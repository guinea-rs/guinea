Глобальный шорткат позволяет показать скрытое окно или отправить команду,
пока фокус находится в другом приложении. Включи Cargo-фичу `global-hotkeys`
и импортируй типы из `guinea::hotkeys`; отдельная клавиатурная библиотека
приложению не нужна.

Регистрируй сочетание в фиче, которая обрабатывает команду.
`cx.global_hotkey` принимает привязку и функцию, создающую сообщение.
Сообщение получает обработчик, зарегистрированный в той же фиче.

## Сочетание в настройках

Здесь `setting` — реактивный `Option<HotKey>`, реализующий
`guinea::sources::Changing`. Для amethystate подходит адаптер `.changing()`
из `amethystate_guinea::IntoChanging`. Открывает и хранит настройки само
приложение.

<!-- shown: hotkeys: binding -->
```rust
struct TogglePanel {
    shortcut: HotKey,
    state: HotKeyState,
}

let binding = cx.global_hotkey(HotkeyBinding::follows(setting.clone()), |event| {
    TogglePanel {
        shortcut: event.shortcut,
        state: event.state,
    }
})?;
```
<!-- /shown -->

`HotKey`, `Modifiers`, `Code` и `HotKeyState` доступны через
`guinea::hotkeys`. У `HotKey` есть поддержка serde: этот же тип можно
хранить в настройках. Постоянную привязку можно передать прямо как `HotKey`.

Событие содержит сработавшее сочетание и состояние: нажатие или отпускание.
Модификаторы описывают зарегистрированное сочетание; дополнительные зажатые
клавиши в них не отражаются. Для переключения панели обрабатывай только
`HotKeyState::Pressed`.

## Переназначение и конфликты

При изменении настройки сначала регистрируется новое сочетание, затем
освобождается старое. Если новое занято, старое продолжает работать.
Значение `None` снимает регистрацию.

Возвращённый `binding.status` — это `Feed<HotkeyStatus>` с полями
`requested`, `effective` и `error`. После конфликта запрошенное сочетание
может отличаться от работающего. Подпишись на этот фид, чтобы показать
ошибку в редакторе шорткатов. Ошибка первой регистрации возвращается через
`?`, последующие публикуются в фиде.

Для редактора шорткатов используй `HotkeyBinding::follows(setting).recovering()`.
При начальном конфликте регистрация остаётся неактивной, а `status.error`
содержит ошибку: приложение продолжит запуск. Изменение настройки повторит
регистрацию без временной записи `None` в сохранённое значение. Ошибки создания
нативного менеджера хоткеев по-прежнему возвращаются через `?`.

События, уже захваченные для прежней регистрации, после успешной смены
отбрасываются. Это работает и при смене сочетания туда и обратно.

## Время жизни

Регистрацией владеет скоуп. Удаление возвращённого хендла её не снимает;
удаление скоупа освобождает сочетание, подписку на настройки и обработчик.
Спящий скоуп сохраняет регистрацию, но пропускает события без очереди
для последующего пробуждения.

Шорткат для показа скрытой панели регистрируй в фиче приложения: тогда он
не зависит от страницы панели. Политика нативного окна и `WindowVisuals`
не владеют глобальными шорткатами.

Интеграция использует нативный цикл событий бэкенда. Поддерживаются Windows,
macOS на основном потоке и Linux/X11. Wayland-порталы и шорткаты отдельного
контрола — другие возможности. Guinea владеет обработчиком событий
нижележащей библиотеки; не заменяй его и не читай её receiver самостоятельно.
