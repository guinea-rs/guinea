# Бэклог

## Изображения в WinUI Reactor

Отложено 22 октября 2026. Не менять вендор для обхода этих проблем.

### Повторная загрузка изображений при возврате на страницу

- В репро страница A содержит одну иконку, B — 27. PNG-байты постоянные.
- При возврате на B её заголовок иногда появляется на 1–2 записанных кадра
  раньше остальных 26 иконок; запись велась с частотой 120 кадров/с.
- Воспроизводится через guinea с raw Image, через guicons и в отдельном
  репро на Reactor без guinea.
- В используемом windows-reactor-pre 0.105.0 кэш держит слабые ссылки на
  нативные источники. Освобождённые источники удерживаются только до конца
  текущего пакета изменений; возврат на страницу запускает загрузку заново.
- Контроль с постоянными невидимыми Image удерживает источники живыми:
  за пять записанных возвратов разрыва не было. Это диагностический приём,
  не предлагаемое исправление.
- Тест всех промежуточных пакетов guinea, включая сообщения обновления
  уходящей страницы, проходит на 32 seed'ах: общая иконка не уничтожается,
  её Source не сбрасывается. Отдельного пустого обновления в этом сценарии
  не обнаружено.
- Дальше: обсудить время жизни декодированного кэша и политику его очистки
  в апстриме. Стабильность исходных байтов не решает время жизни этого кэша.

### Качество SVG при масштабировании

- В чистом Reactor сравнивались одинаковые геометрии пяти SystemTools-иконок
  в Image размером 32×32.
- Исходные SVG с 1em, явными 24×24 и только viewBox дают одинаковый
  замыленный результат. При явных 32×32 результат чище; при 128×128
  заметны ступеньки. Контроль — PNG, полученный через resvg.
- Полутоновые пиксели на границах есть: полного отключения сглаживания
  не обнаружено. Точная причина зависимости от внутренних размеров пока
  не установлена.
- Дальше: закончить сравнение загрузки SVG из памяти и по файловому URI;
  проверить фактическое разрешение растеризации и RasterizePixelWidth/Height,
  момент загрузки относительно включения Image в живое дерево и DPI.

Локальные репро и записи находятся в игнорируемом target:
guinea-image-repro, reactor-routing-repro, png-guinea-raw-primary.mkv,
png-reactor-desktop.mkv, png-guicons-desktop.mkv, png-reactor-kept.mkv,
svg-quality-capture.png. Эти артефакты не входят в репозиторий.
